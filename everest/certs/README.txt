Put your SECC certificates here if using Plug&Charge (PnC):

- ca/v2g/V2G_ROOT_CA.pem           # CA bundle for V2G TLS
- client/cso/secc_leaf.pem         # SECC leaf certificate (PEM)
- client/cso/secc_leaf.key         # SECC private key (PEM)

Adjust paths in `EvseSecurity` config (`everest/config/plc_only.yaml`) accordingly.
